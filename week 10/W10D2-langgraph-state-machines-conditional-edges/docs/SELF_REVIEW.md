# Self-review checklist

- [ ] I installed dependencies in a clean virtual environment.
- [ ] All automated tests pass locally.
- [ ] I manually verified each expected route.
- [ ] I tested the interrupt pause and resume path where applicable.
- [ ] I reviewed typing, naming, comments, and error handling.
- [ ] I added terminal/test output or screenshots as evidence.
- [ ] I requested CIA Full Stack Mentor Mode review and logged two interactions.
- [ ] I made at least two descriptive commits on the required branch.
- [ ] I pushed the branch and opened a PR.
- [ ] I checked the PR diff and added a clear description.
