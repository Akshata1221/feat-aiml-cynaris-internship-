# W1D1: Python for ML — NumPy Fundamentals

## Objective

This project demonstrates fundamental NumPy operations required for Python-based machine learning.

## Topics Covered

- 1D, 2D, and 3D NumPy arrays
- Array shape verification
- Broadcasting
- Vectorised operations
- Matrix multiplication
- Mean calculation
- Standard deviation
- Correlation analysis

## Dataset

The project uses `organizations.csv` as a real CSV dataset for statistical analysis.

The numerical columns analyzed are:

- Index
- Founded
- Number of employees
