\# W1D2 - Pandas for Data Manipulation



\## Overview



This project demonstrates fundamental Pandas data manipulation techniques using an India COVID-19 case time-series dataset.



\## Dataset



The dataset contains 100 records with daily and cumulative COVID-19 statistics for India.



Columns include:



\- Date

\- Date\_YMD

\- Daily Confirmed

\- Total Confirmed

\- Daily Recovered

\- Total Recovered

\- Daily Deceased

\- Total Deceased



\## Operations Implemented



The project demonstrates:



1\. Loading a CSV dataset using Pandas

2\. Inspecting shape, data types, and first 10 rows

3\. Data cleaning and duplicate removal

4\. Filtering records

5\. GroupBy aggregation

6\. DataFrame merging

7\. Pivot table creation

8\. Exporting data to CSV

9\. Exporting data to Parquet

10\. Comparing CSV and Parquet file sizes
