- [ ] Three agents have distinct roles, goals and backstories.
- [ ] Three tasks are assigned to the correct agents.
- [ ] Sequential crew executes successfully with configured LLM credentials.
- [ ] Web search tool returns URLs and useful snippets.
- [ ] Same topic tested in offline and web modes; improvement documented.
- [ ] Report claims checked against source pages; unsupported claims removed.
- [ ] LangChain/Ollama chain tested with five inputs and history across five turns (optional extension).
- [ ] LangGraph path tested.
- [ ] MLflow run and report artifact visible in tracking UI.
- [ ] Ragas evaluation run on a properly populated evaluation dataset.
- [ ] Unit tests pass.
- [ ] No secrets or `.env` file committed.
- [ ] At least two descriptive commits exist on the required feature branch.
- [ ] Output evidence captured from an actual run.
- [ ] Two CIA Full Stack Mentor Mode interactions logged in course system.
- [ ] Pull Request opened and reviewed.
