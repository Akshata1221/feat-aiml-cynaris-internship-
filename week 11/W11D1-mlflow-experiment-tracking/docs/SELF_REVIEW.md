# Self-review checklist

- [ ] Create a clean virtual environment and install dependencies.
- [ ] Run `pytest -q` and save terminal output as evidence.
- [ ] Verify model parameters, metrics, and artifacts in MLflow.
- [ ] Compare all five runs and identify the best candidate.
- [ ] Register and load the selected model (where applicable).
- [ ] Test the REST endpoint or RAG evaluation path (where applicable).
- [ ] Capture MLflow UI / serving / evaluation evidence.
- [ ] Request CIA Full Stack Mentor Mode review and log two interactions.
- [ ] Make at least two descriptive commits on the required branch.
- [ ] Push the branch and open a PR.
